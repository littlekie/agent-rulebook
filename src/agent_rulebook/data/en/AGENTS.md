# AI development instructions

Before implementing, fixing, refactoring or reviewing code, read
`docs/ai-governance/engineering.md`. It defines task boundaries, acceptance evidence,
architecture constraints and L0/L1/L2 review requirements. Follow applicable
directory instructions and the current task's explicit authorization.

For code review, also read `REVIEW.md`. For CI, risk policy or automated release
changes, read `docs/ai-governance/SETUP.md` before editing configuration.

Use this repository's actual toolchain, lockfiles and commands. Preserve existing
work and report only checks actually performed. Instructions alone do not activate
CI, authorize publication or permit merging.
